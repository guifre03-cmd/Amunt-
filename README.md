# Amunt! App

## Provar en local
1. Instal·la Node.js.
2. Obre una terminal dins la carpeta.
3. Executa `npm install`.
4. Executa `npm run dev`.

## Publicar a Vercel
1. Puja aquesta carpeta a un repositori de GitHub.
2. A Vercel, prem Add New > Project.
3. Importa el repositori.
4. Framework Preset: Vite.
5. Build Command: `npm run build`.
6. Output Directory: `dist`.
7. Prem Deploy.

Quan estigui publicada, Android mostrarà l'opció d'instal·lar. A iPhone: Safari > Compartir > Afegir a la pantalla d'inici.
